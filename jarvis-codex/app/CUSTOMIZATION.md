# Customization

Common controls are in the app; no source edit is needed. Save settings to apply them. Saving stops active audio so a provider, voice or device cannot change in the middle of a queue.

- **Connections:** Claude/OpenAI, exact account model, voice ID/name, Flash v2.5 or Multilingual v2, stability, similarity and speed. The selected model must support the requested API. Account catalog access and paid generation are different checks. Preview consumes usage.
- **Audio:** explicit input/output, volume, speech toggle, utterance timeout, silence endpointing, global talk/Stop shortcuts, local wake sensitivity, refractory interval and optional cloud follow-up duration. No custom phrase text box pretends to train a model.
- **Character:** transparent PNG/WebP import; 8 MB / 64–4096 px limits; Orbit, Drift, Still; amplitude, period, glow, gold/violet colors, energy trails and reduced motion. A decoded copy is kept in app data. The supplied master remains unchanged in the source pack.
- **Overlay:** size, opacity, left/right dock, display, always-on-top, idle collapse delay, always/on-demand/hidden visibility. Drag only by its handle. Off-screen positions clamp into a current display's work area. Click-through pixel handling and multi-monitor behavior still require the physical Windows checks documented in TEST_REPORT.md.
- **Memory:** explicit create/edit/forget, export, owner address, assistant name, humor, reply length, system personality and custom instructions. Memories are context, not privileged instructions. “Remember that …” saves locally and acknowledges only after writing succeeds.
- **Usage:** per-session turn, speech character, connected STT duration, reply-token and context limits. These limits are not a currency budget or provider billing cap. No guessed USD pricing is shown.

Visual direction: **Subject** — the supplied falcon-inspired guardian, sharp and readable, no replacement image. **Environment** — a transparent desktop overlay and charcoal workspace with gold/violet accents. **Camera** — fixed frontal image, contain scaling with original alpha. **Sequence** — compact idle badge; reveal for listening/thinking/speaking; actual input/playback levels drive glow; collapse after idle. A single PNG provides no mouth lip-sync.

The preview buttons simulate only labels and motion. They make no network/device calls, and leave input/output levels at zero. Exit preview before real setup. System reduced-motion settings are respected. The character may be covered by exclusive full-screen software.
